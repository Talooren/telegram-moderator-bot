# Telegram Moderator Bot — Модерация публикаций в Telegram-канал

Бот для приёма сообщений от пользователей по шаблону, модерации в отдельном чате и публикации одобренных сообщений в целевой канал.

## 🎯 Что делает

Принимает от пользователей структурированные сообщения по шаблону («Кому: <отдел>», «От кого: <отдел>», один из тегов #Задача / #Вопрос / #Ответ / #Предложение, тело после тега) и отправляет их в модераторский чат с inline-кнопками «Одобрить / Отклонить». Модераторы (админы модераторского чата) рассматривают заявку: при одобрении сообщение публикуется в целевой канал, при отклонении — отправитель получает уведомление в ЛС. Включает HTTP-сервер (aiohttp) для деплоя на платформах типа Render.

## 🛠 Архитектура / Технологии

- **Язык:** Python 3
- **Telegram:** aiogram 3.x
- **HTTP:** aiohttp (веб-сервер для Render)
- **Валидация:** regex (структура сообщения, теги)
- **Структура:** один файл main.py (~250 строк)

## 📦 Статус

🟡 Ранний прототип (MVP). Функциональный — приём, модерация, публикация работают. Структура минимальна: весь код в одном файле без разделения на модули. Подходит как основа для доработки.

## 🔐 Безопасность

Секреты (.env, токен бота) не включены в репозиторий.
